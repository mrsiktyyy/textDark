# textDark 3.2

Тёмный редактор для текста и кода на PySide6. В нём теперь два режима работы: привычное окно для программирования и отдельный форматированный блокнот для заметок, картинок и таблиц.

## Что внутри

| Возможность | Программирование | Блокнот |
|---|:---:|:---:|
| Вкладки и несколько документов | ✓ | ✓ |
| Нумерация строк | ✓ | — |
| Базовая подсветка синтаксиса | ✓ | — |
| Автозакрытие скобок и кавычек | ✓ | — |
| Жирный, курсив, подчёркивание | ✓ | ✓ |
| Изображения | — | ✓ |
| Таблицы, строки и столбцы | — | ✓ |
| Объединение и разделение ячеек | — | ✓ |
| Настройка внутренних границ таблицы | — | ✓ |
| Автовосстановление | ✓ | ✓ |

## Что нового в 3.2

- В настройках появились два режима: **Программирование** и **Блокнот**.
- В режиме «Блокнот» работает форматированный текст, вставка изображений, таблиц, списков, заголовков, ссылок и цитат.
- Таблицы можно создавать с нужным количеством строк и столбцов, добавлять/удалять строки и столбцы, объединять и разделять ячейки, убирать внутренние вертикальные и горизонтальные линии в выделенной области.
- В `.txtd` сохраняются форматирование и встроенные изображения. Старые `.txtd` с обычным текстом по-прежнему открываются.
- В режиме «Программирование» сохранены нумерация строк, подсветка, автозакрытие скобок и основные операции со строками.
- Команды, относящиеся к строкам и коду, скрываются в режиме «Блокнот»; инструменты форматированного документа доступны только в нём.
- Меню «Инструменты» содержит одну общую статистику документа без дублирующих счётчиков слов, символов и строк.
- «Символ...» и «Эмодзи...» вызывают системную панель Windows `Win + .`.
- Масштаб: `Ctrl + =`, `Ctrl + -`, `Ctrl + 0` и `Ctrl + колесо мыши`.
- В расширенных настройках можно включить сворачивание в системный трей и настроить сочетания клавиш для команд меню.
- Сохраняются режим редактора, масштаб, шрифт, фон, положение и размер окна, сочетания клавиш и настройка трея.
- При первом запуске появляется короткое интро во время подготовки интерфейса.

## Форматы и сохранение

- Обычные текстовые и исходные файлы открываются как UTF-8.
- `.txtd` использует AES-256-GCM и автоматически шифруется/расшифровывается без пароля.
- В режиме «Блокнот» полный форматированный документ, включая изображения и таблицы, сохраняется в `.txtd`.
- При сохранении форматированного документа в `.txt`, `.py` и другие обычные текстовые форматы останется только текст. Для сохранения форматирования используй `.txtd`.
- Автовосстановление несохранённых вкладок хранится в локальной папке приложения в зашифрованном виде.

## Системный трей и приложение по умолчанию

Вкладка «Расширенные» настроек позволяет включить сворачивание в трей при нажатии на крестик. Для полного выхода используй пункт «Выход» в меню значка textDark в трее. Если работаешь в Windows без доступного системного трея, эта настройка будет недоступна.

Регистрация textDark для текстовых файлов выполняется в разделе текущего пользователя Windows и не требует прав администратора. Для `.txt` Windows может попросить выбрать приложение в системном окне «Приложения по умолчанию» — изменить системный выбор в обход этого окна приложение не пытается.

## Важно о защите `.txtd`

Все копии textDark используют общий ключ, встроенный в приложение. Это позволяет обмениваться `.txtd` без пароля, но технически подготовленный человек может извлечь ключ из EXE. Поэтому `.txtd` не подходит для хранения паролей, ключей доступа и особо конфиденциальных данных.

## Запуск из исходников

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## Сборка одного EXE (Windows)

Положи `logo.png` рядом с `main.py`, затем выполни:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\build.ps1
```

Готовый файл: `dist\textDark.exe`. Скрипт сам создаёт `.venv`, устанавливает зависимости и PyInstaller, делает `logo.ico` и собирает EXE для Windows x64. Для первой сборки нужен интернет.

`Ctrl + колесо мыши` меняет масштаб, а `Win + .` открывает стандартную панель эмодзи и символов Windows.

> Скрипт `scripts/build.ps1` содержит только ASCII в текстовых сообщениях — это сделано для совместимости с Windows PowerShell.
