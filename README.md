## 👋 Что такое textDark?

**textDark** — небольшой текстовый редактор со своим секретным форматом файлов.

Пиши заметки, редактируй конфиги, открывай исходный код и переключайся между файлами в одном окне. Нужные команды собраны в привычных меню.

> Проект создан **mrsiktyyy** при помощи **ChatGPT Free** и **Gemini AI**.

## 🔐 Формат `.txtd` — что это?

У textDark есть собственный формат документов **`.txtd`**. При сохранении содержимое шифруется, а при открытии автоматически расшифровывается.

| Вопрос | Ответ |
|---|---|
| Нужен пароль? | Нет. Шифрование и расшифровка происходят автоматически. |
| Можно открыть в textDark на другом компьютере? | Да. Копии приложения используют общий встроенный ключ. |
| Будет ли файл читаться в обычном Блокноте? | Нет, содержимое хранится в зашифрованном виде. |
| Подходит ли формат для особо важных секретов? | Нет. Встроенный ключ можно извлечь из приложения при целенаправленном техническом анализе. |

<details>
  <summary><strong>⚠️ Важное предупреждение о безопасности</strong></summary>
  <br>
  Все копии textDark используют один и тот же ключ, встроенный в приложение. Это сделано для того, чтобы файлы `.txtd` можно было передавать другим пользователям textDark без обмена паролями.

  Но это не полноценное хранилище секретов: технически подготовленный человек может попытаться извлечь ключ из EXE. Поэтому не сохраняйте в `.txtd` пароли, ключи доступа и другую особо конфиденциальную информацию.
</details>

## ⚙️ Установка и запуск

Есть два способа запустить textDark: из исходного кода или собрать отдельный EXE-файл.

### Вариант 1. Запуск из исходников

Понадобится установленный Python и доступ к интернету для загрузки зависимостей.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

### Вариант 2. Сборка одного EXE

Скрипт сборки сам подготовит виртуальное окружение, установит зависимости и запустит PyInstaller.

**Перед сборкой:** положи `logo.png` рядом с `main.py`. Это необязательно, но файл используется для создания иконки приложения.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\build.ps1
```

После завершения сборки готовое приложение будет здесь:

```text
dist\textDark.exe
```

<details>
  <summary><strong>🔧 Что делает скрипт сборки?</strong></summary>
  <br>

  - Создаёт виртуальное окружение `.venv`, если его ещё нет.
  - Устанавливает библиотеки из `requirements.txt` и PyInstaller.
  - При наличии `logo.png` запускает `scripts\make_icon.py` для создания `logo.ico`.
  - Собирает приложение в один EXE-файл с помощью PyInstaller.

  Для первой сборки нужен интернет, чтобы скачать зависимости. Готовый EXE предназначен для **Windows x64**.
</details>
