# textDark 3.1

Тёмный редактор текста и кода на PySide6 с меню Файл, Правка, Формат, Вставка, Вид, Инструменты и Справка.

## Возможности
- Вкладки и несколько открытых документов.
- Нумерация строк, текущая строка, базовая подсветка синтаксиса.
- Автозакрытие скобок и кавычек, базовый автоотступ.
- Открытие обычных текстовых и исходных файлов UTF-8.
- Формат `.txtd`: AES-256-GCM, автоматическое шифрование/расшифровка, без пароля.
- Автовосстановление несохранённого текста в локальной папке приложения.
- Только тёмная тема.

## Что нового в 3.1 (исправления после редизайна 3.0)
- Вкладки: убран символ «●» из названия (он «плавал» ниже центра), крестик теперь вплотную к названию. Несохранённый файл показывается точкой на месте крестика; при наведении точка плавно превращается в крестик.
- Файл → «Настройки...» (Ctrl+,): фон приложения за текстом (изображение, прозрачность, затемнение, размытие, живой предпросмотр) и переключатель «Использовать textDark для текстовых файлов» (замена Блокнота).
- Справка → «Сайт / Скачать» (ссылка на GitHub с релизами); в «О программе» исправлены авторы и добавлена та же кнопка.
- Анимации (150–250 мс): появление окна, выпадающих меню, диалогов, плавная смена содержимого вкладок, переключатель и кнопка закрытия вкладки.

## Настройка ссылки на GitHub
В начале `main.py` замените значение `GITHUB_URL` на адрес вашей страницы релизов.

## Замена Блокнота (Windows)
Переключатель в настройках регистрирует textDark в системе (раздел текущего пользователя в реестре, права администратора не нужны) и открывает окно Windows «Приложения по умолчанию». Файлы `.txtd` привязываются сразу. Для `.txt` и других типов Windows требует, чтобы пользователь сам выбрал приложение в этом окне: так устроена защита системы, обойти её программа не может. Выключение переключателя удаляет регистрацию.

## Фон приложения
Фон хранится в настройках пользователя (путь к изображению и значения ползунков). Само изображение не копируется, поэтому не перемещайте файл. Если файл удалён, приложение работает с обычным тёмным фоном.

## Важно о защите `.txtd`
Все копии textDark используют общий встроенный ключ. Это позволяет любому пользователю приложения открывать файлы без пароля и обмениваться ими напрямую. Файлы не читаются как обычный текст. Однако ключ можно извлечь из самого приложения при целенаправленном анализе EXE, поэтому `.txtd` не подходит для секретных данных против технически подготовленного атакующего. Не отправляйте через него пароли и особо конфиденциальную информацию.

## Запуск из исходников
```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## Сборка одного EXE (Windows)
Положите `logo.png` рядом с `main.py` (если нужна иконка), затем:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\build.ps1
```
Готовый файл: `dist\textDark.exe`. Для сборки нужен интернет, чтобы установить зависимости. Полученный EXE предназначен для Windows x64.

Скрипт сам создаёт `.venv`, ставит зависимости и PyInstaller, превращает `logo.png` в `logo.ico` (`scripts\make_icon.py`) и собирает EXE.


Build script note: `scripts/build.ps1` contains ASCII-only text to avoid Windows PowerShell encoding/parser issues.
